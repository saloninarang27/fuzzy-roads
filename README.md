# Delhi Address Alchemy: RDR-Powered Road-Type Normalisation

This repository contains the IIA Home Assignment A2 submission on
normalising synthetic Delhi address data with Ripple-Down Rules, fuzzy string
matching, phonetic matching, and lookup-table generation.

See the complete submission in [`A2_Submission/`](./A2_Submission/), including
the reviewed implementation, baseline code, report, sample data, and output
lookup tables.

The full 10-million-row synthetic CSV is intentionally excluded because it is
approximately 1 GB. The included sample and reviewed code are sufficient to
understand and reproduce the workflow.
